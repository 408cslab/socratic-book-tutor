# 学习进度记忆

所有运行数据存用户工作区 `<workspace>/.socratic-tutor/<领域>/`，不写 Skill 包。

## 1. 目录与文件

| 文件 | 内容 | 何时写 |
|---|---|---|
| `md/*.md` | 转换 + 校对后的知识库 | 阶段一建库时 |
| `index.md` | 知识索引（文档→章→节→知识点） | 阶段一建库时 |
| `progress.md` | 学习进度：当前位置（覆盖写）+ 薄弱点（追加写） | 阶段二每次学完一个知识点 / 退出时 |

## 2. progress.md 格式（覆盖区 + 追加区）

**覆盖区**（每学完一个知识点覆盖写，只保留最新位置，历史不累积）：

```
### 更新于 {YYYY-MM-DD HH:mm}
- 领域：{领域名}
- 当前位置：第 {N} 个知识点（{知识点名}）
- 总知识点数：{M}
```

**追加区**（只追加、去重，用户掌握后可标移除）：

```
### 薄弱点（累计）
- {知识点A}（{日期}，连续答错 3 次）
- {知识点B}（{日期}，连续答错 3 次）
```

- 薄弱点**只追加不覆盖**，同名去重；用户后续掌握某点 → 在该行标 `[已掌握]` 或移除该行。
- 用户中途退出 → 立即写覆盖区「当前位置」并明说「已保存」。

## 3. 续学

- 用户说「继续上次」→ 读 `progress.md` 覆盖区的「当前位置」，从该知识点开始。
- 无 `progress.md` 或字段缺失 → 从 `index.md` 第一个知识点开始。
- 「列出薄弱点复习建议」读追加区「薄弱点（累计）」，而不是覆盖区。

## 4. `<workspace>` 三级解析（先做，逐级探测可写性）

按顺序探测，取第一个**可写**的作为 `<workspace>`：

1. 环境变量 `$WORKSPACE`（存在且可写则用）；
2. Bash 工具的 cwd（`$PWD`，通常即用户工作区）；
3. 用户主目录 `$HOME`（最后兜底）。

- 首轮回复一句话告知持久化状态：「已记录，下次可接着学」或「本次进度未持久化（仅会话内记忆）」。
- 三级都不可写 → 降级为「会话内记忆」，提示用户「本次进度未持久化」。
- 不写 Skill 安装目录、不写系统临时目录。

## 5. 红线

- 不把路径、内部字段、写入动作写进回复。
- 不主动索要敏感信息；领域名、进度都是用户主动提供的。
