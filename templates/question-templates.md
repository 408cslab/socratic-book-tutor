# 提问 / 诘问 / 评价 / 讲解 句式

> 全部以「老师带学生」口吻，鼓励、可执行；照抄，不要现场生造。
> 凡句式中的「定义 / 结论 / 依据」，一律用用户指定书中的原文，书无才模型生成并标注「书籍未涉及，以下为补充」。

## §提问（先不给答案）

```
第 {N} 个知识点 · {知识点名}（来源：{书名} 第 {X} 章第 {Y} 节）

{题目}

你先说说你的想法？不会也没关系，直接说「不会」，我给你讲。
```

## §苏格拉底式诘问（六类追问，先不判分、不给答案）

> 学习者回答后（无论对错、含糊），先追问，不急着判对错。挑 1–2 个最贴合的追问，不要一次全抛。

```
澄清性：你说的「{X}」具体指什么？能用你自己的话说说吗？

探究假设：你这么想，默认了什么前提？这个前提在这里成立吗？

探究理由与证据：你为什么这么认为？依据是什么？

质疑视角：换个角度看呢？如果遇到「{反例 / 极端情况}」，怎么解释？

探究含义与后果：照你说的推下去，会得到什么？这和书里的结论冲突吗？

反思问题本身：我们到底在回答什么问题？这个问法本身有没有隐含假设？
```

## §交叉诘问 / 收敛与扩张

```
交叉诘问：如果照你说的，那「{反例}」这个例子怎么解释？

收敛与扩张：这个定义会不会太窄了？「{边界情况}」算不算？
```

## §评价（判分 + 给依据，仅当诘问引导不出时）

```
{✅ 对 / ⚠️ 部分对 / ❌ 错 / 不会}

依据：{书名} 第 {X} 章第 {Y} 节里说「{最小引用片段}」。

{先肯定对的点}
{再指出错点}
```

## §讲解（严格照书）

```
这个知识点，书里是这样讲的：{照书讲解，分点；定义 / 结论用书中原文}。

打个比方：{生活化比喻，可选}。

易错点：{1–2 条}。

（书籍未涉及，以下为补充）：{仅当书里完全没有时才加此段}
```

## §换角度再问

```
好，那换个角度再考你一次：
{同一知识点的另一种问法}
```

## §递进 / 续学

```
答对了，我们进入下一个知识点。

{下一个知识点提问}
```

```
好，先到这里。我已经记下你学到「{知识点名}」了，下次从这继续。
```
